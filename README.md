Simple Banking Management System – Java & MySQL

A console-based Java application that simulates basic banking operations like account creation, login, and secure storage using a MySQL database via JDBC.

<img width="808" height="1348" alt="image" src="https://github.com/user-attachments/assets/72006775-52ee-4b52-b8c7-a2749e78192e" />

Features
✅ Create New Bank Accounts (with PIN, Name, Age)
🔐 Secure Login with PIN Authentication
🗄 Data stored in MySQL using JDBC
📦 Object-Oriented Structure with classes like Account, AccountCreation, and DatabaseConnection



Technologies Used
Tech	              Purpose
Java                (Core)	Console application logic
JDBC	              Database connectivity
MySQL	              Backend data storage
IntelliJ IDEA	      Development environment
Git & GitHub	      Version control & hosting



How to Run
1. Clone this repo
2. Import into IntelliJ (or any IDE)
3. Ensure MySQL is running and update DatabaseConnection.java credentials
4. Run Main.java
